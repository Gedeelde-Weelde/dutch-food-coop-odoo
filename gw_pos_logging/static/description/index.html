POS Order Logging

Comprehensive logging for POS operations in browser database

This module adds comprehensive logging functionality to the Point of Sale (POS) system, tracking the complete order lifecycle from creation to completion.

Features

Order Lifecycle Logging:

  • Order creation and product operations
  • Payment operations (add, delete, validate)
  • Order completion and receipt events
  • Screen transitions and state changes

Technical Benefits:

  • Stores logs in browser's IndexedDB
  • Export logs as CSV files for analysis
  • No server-side storage required
  • Minimal impact on POS performance
  • Error and exception tracking
  • Session and system event monitoring

Technical Information

Logged Events:

  • Product Screen: Order creation, product additions/removals, quantity changes, order cancellation
  • Payment Screen: Adding/deleting payment lines, payment validation
  • Receipt Screen: Order completion, receipt printing, next order actions
  • System Events: Session start/end, errors and exceptions

Database Structure:

  • Payment Logs DB: Stores detailed payment operation logs
  • Order Logs DB: Stores comprehensive order lifecycle events
  • Key Indexes: timestamp, order_uid, action, screen
  • Common Fields: action, timestamp, order information
  • Event-specific Fields: Product details, payment information, error data

Usage

The module works automatically after installation. No configuration is needed.

Viewing Payment Logs:

  1. Open the browser's developer console (F12)
  2. Go to the "Application" tab
  3. Under "Storage", expand "IndexedDB"
  4. Select "pos_payment_logs" database
  5. View the "payment_logs" object store

Viewing Order Logs:

  1. Open the browser's developer console (F12)
  2. Go to the "Application" tab
  3. Under "Storage", expand "IndexedDB"
  4. Select "pos_order_logs" database
  5. View the "order_logs" object store

You can use the IndexedDB browser interface to filter logs by various indexes such as timestamp, order_uid, action, or screen.

Exporting Logs as CSV:

  1. Open the POS interface
  2. On the Product Screen, click the "Export Logs" button in the control panel
  3. Two CSV files will be downloaded automatically:
    • payment_logs_YYYY-MM-DD.csv - Contains all payment logs
    • order_logs_YYYY-MM-DD.csv - Contains all order logs
  4. The CSV files can be opened in any spreadsheet application (Excel, Google Sheets, etc.)
  5. Each CSV file includes all fields from the logs, with headers in the first row
