This module logs POS payment operations and events to browser's IndexedDB database
with CSV export functionality for debugging and analysis purposes.

Features
========

* Logs payment operations to browser's IndexedDB
* Export logs as CSV files
* Debug widget integration
* Payment validation tracking

Usage
=====

To use this module:

1. Install the module
2. Open POS interface
3. Access Debug Widget (enable developer mode)
4. Use "Export Logs" to download CSV files
